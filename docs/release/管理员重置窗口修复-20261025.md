# 管理员手动重置统计窗口修复与用户 Key 恢复

后续并发与失败补偿改版已另行记录，当前实现见 [管理员重置并发与补偿修复](管理员重置并发与补偿修复-20261025.md)。本文保留首次修复的历史事实。

时间：2026-10-25，北京时间。

## 问题与修复

管理员原生 `reset-quota` 接口将订阅用量清零，但日统计窗口仍写为当天零点。
额度控制器通过 `usage_logs` 按窗口求和，所以仍计入手动重置之前的消费，再次停用 Key。
用户 18 的订阅 57、126 今日重置前分别消费 $80.088797、$10.275360，超过 $80、$10 日限额。

自有 `subscription-reset-service/admin-reset.mjs` 接管两个管理员路径：

- `/api/v1/admin/subscriptions/:id/reset-quota`
- `/v1/admin/subscriptions/:id/reset-quota`

请求先沿用调用者 Bearer token 请求内部 Sub2API 管理员接口，保留其鉴权、审计和缓存失效。
上游成功后，将 catalog 中固定日额度套餐所选的日/周/月窗口同步到请求前捕获的数据库时间。
同步时不再次清零计数器，保留重置过程中完成的请求消费；有效期不变。
未选择的窗口和累计套餐保持原行为，失败不能返回同步成功。
自动日重置继续请求内部上游地址并归一到北京时间零点。

Caddy 的三个既有用户重置匹配器均增加管理员路径，其余路由保留。
仅重建自有重置服务，未修改或重启 Sub2API、额度控制器及账号池。
